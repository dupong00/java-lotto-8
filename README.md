# 로또 시뮬레이션

해당 프로젝트는 헥사고날 아키텍처(포트와 어댑터)를 적용하여 로또 시뮬레이션 기능을 CLI 환경에서 구현합니다.
도메인 중심 설계(DDD)와 유연한 확장성을 검증하기 위해 수동 구매 및 API 연동 기능을 추가 구현했습니다.

## 아키텍처

프로젝트는 헥사고날 아키텍처를 기반으로 합니다.

## 주요 기능 목록

1. 로또 구입 금액 입력 기능
2. 로또 발행 및 출력 기능 (수동 구매, 자동 구매)
3. 당첨 번호 및 보너스 번호 입력 기능 (외부 API 호출 가능)
4. 당첨 통계 계산 기능
5. 결과 출력

### 1단계 : Domain 계층 (핵심 비즈니스 규칙)

- [x]  **1. 로또 번호 규칙 정의**
    - 6개의 숫자를 가져야 함
    - 숫자는 1~45 범위 내여야 함
    - 숫자는 중복될 수 없음
        - [예외] 위 규칙 중 하나라도 위반 시 예외 발생
- [x]  **2. 당첨 번호 및 등수 계산 규칙 정의**
    - 당첨 번호(6개)의 유효성 검증
    - 보너스 번호(1개)의 유효성 검증 (1~45 범위)
        - [예외] 보너스 번호가 당첨 번호와 중복 시 예외 발생
    - 1등~5등 및 꽝을 판별하는 등수 계산 기능
    - 등수별 당첨 금액 정의 (e.g., 1등 20억, 2등 3천만...)
- [x]  **3. 통계 계산 규칙 정의**
    - 발행된 여러 장의 로또를 등수별로 집계하는 기능
    - 총 구매 금액 대비 총 당첨금의 수익률 계산 기능
    - 수익률은 소수점 둘째 자리에서 반올림
- [x] **4. 돈 규칙 정의**
  - 금액이 1000원 단위인지, 최소 금액 이상인지 검증
      - [예외] 위 규칙 중 하나라도 위반 시 예외 발생

### 2단계 : Application 계층 (유스케이스)

- [x]  **5. 로또 구매 기능 구현**
  - 구입 금액과 수동 번호 목록 받음
  - Money 도메인을 통해 수동 구매 처리 및 잔액 계산
  - 남은 잔액으로 자동 로또 생성 및 저장
- [x]  **6. 당첨 통계 기능 구현**
    - 저장된 당첨 번호와 사용자 로또 목록을 조회 요청
    - 조회된 데이터를 기반으로 도메인에 등수 계산 및 통계 집계 요청
    - 최종 통계 결과를 반환
- [x]  **7. 당첨 번호 기능 구현**
  - 당첨 번호(6개) 입력값이 숫자인지, 콤마(,)로 구분되었는지 검증
    - [예외] 형식이 올바르지 않은 경우(숫자가 아니거나, 콤마 구분이 아니거나) 예외 처리
  - 보너스 번호 입력값이 숫자인지 검증
    - [예외] 입력값이 숫자가 아닌 경우 예외 처리

### 3단계 : Adapter 계층

- [x]  **8. CLI 입력 어댑터 구현**
    - 구매 금액 입력
    - 당첨 번호(쉼표 구분) 및 보너스 번호 입력
- [x]  **9. CLI 출력 어댑터 구현**
    - 구매한 로또 수량과 번호 목록을 형식에 맞게 출력
    - 당첨 통계(등수별 개수)를 형식에 맞게 출력
    - 총 수익률을 형식에 맞게 출력
- [x]  **10. 외부 API 어댑터 구현**
    - 로또 API 가져오기
