
# 프로젝트 소개
해당 프로젝트는 로또 시뮬레이션 프로젝트입니다. 당첨 번호를 지정한 뒤 시뮬레이션 돌릴 횟수만큼 구입 금액을 입력하게 되면 로또를 구매하고 해당 결과들을 종합하여 당첨 내역을 출력해줍니다.

# 기능 목록
**1. 로또 구입 금액 입력 기능**
- [ ]  로또 구매 금액을 입력받는다.
    - [ ]  [예외] 입력 값이 숫자가 아닌경우 IllegalArgumentException예외를 발생시킨다.

**2. 로또 발행 및 출력 기능**
- [ ]  구입 금액에 해당하는 개수만큼 로또를 발행한다.
- [ ]  1장의 로또는 1~45사이의 중복되지 않는 6개 숫자로 생성한다.
- [ ]  발행한 로또의 총 수량을 출력한다.
- [ ]  발행한 모든 로또 번호를 출력한다.(오름차순으로 정렬)

**3. 당첨 번호 및 보너스 번호 입력 기능**
- [ ]  당첨 번호 6개를 쉼표를 이용해 구분하여 입력받는다.
- [ ]  [예외] 숫자가 1~45를 벗어난 경우 IllegalArgumentException예외를 발생시킨다.
- [ ]  [예외] 6개가 아니거나 중복된 숫자가 있는 경우 IllegalArgumentException예외를 발생시킨다.
- [ ]  보너스 번호 1개를 입력받는다.
- [ ]  [예외] 숫자가 1~45를 벗어난 경우 IllegalArgumentException예외를 발생시킨다.
- [ ]  [예외] 6개가 아니거나 중복된 숫자가 있는 경우 IllegalArgumentException예외를 발생시킨다

**4. 당첨 통계 계산 기능**
- [ ]  입력 받은 당첨 번호와 구매한 로또의 숫자를 비교한다.
    - [ ]  각 번호에 따라 1등부터 5등까지 분류하여 집계한다.
- [ ]  총 당첨 금액을 계산한다.
- [ ]  총 당첨 금액으로 수익률을 계산한다.(수익률은 둘째 자리에서 반올림 한다.)

**5. 결과 출력**
- [ ]  당첨 통계를 형식에 맞게 출력한다.
- [ ]  총 수익률을 형식에 맞게 출력한다.
