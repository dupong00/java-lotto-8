# 로또 시뮬레이션

해당 프로젝트는 헥사고날 아키텍처(포트와 어댑터)를 적용하여 로또 시뮬레이션 기능을 CLI 환경에서 구현합니다.

## 아키텍처

프로젝트는 헥사고날 아키텍처를 기반으로 합니다.

## 주요 기능 목록

1. 로또 구입 금액 입력 기능
2. 로또 발행 및 출력 기능
3. 당첨 번호 및 보너스 번호 입력 기능
4. 당첨 통계 계산 기능
5. 결과 출력

### 1단계 : Domain 계층 (핵심 비즈니스 규칙)

- [x]  **1. 로또 번호 규칙 정의**
    - 6개의 숫자를 가져야 함
    - 숫자는 1~45 범위 내여야 함
    - 숫자는 중복될 수 없음
        - [예외] 위 규칙 중 하나라도 위반 시 예외 발생
- [x]  **2. 당첨 번호 및 등수 계산 규칙 정의**
    - 당첨 번호(6개)의 유효성 검증
    - 보너스 번호(1개)의 유효성 검증 (1~45 범위)
        - [예외] 보너스 번호가 당첨 번호와 중복 시 예외 발생
    - 1등~5등 및 꽝을 판별하는 등수 계산 기능
    - 등수별 당첨 금액 정의 (e.g., 1등 20억, 2등 3천만...)
- [x]  **3. 통계 계산 규칙 정의**
    - 발행된 여러 장의 로또를 등수별로 집계하는 기능
    - 총 구매 금액 대비 총 당첨금의 수익률 계산 기능
    - 수익률은 소수점 둘째 자리에서 반올림

### 2단계 : Application 계층 (유스케이스)

- [x]  **4. 로또 구매 기능 구현**
    - 구매 금액이 1,000원 단위인지 검증
        - [예외] 1,000원 단위가 아닐 경우 예외 발생
    - 구매 금액이 최소 1,000원 이상인지 검증
        - [예외] 1,000원 미만일 경우 예외 발생
    - 구매 금액만큼 로또를 자동으로 생성하는 기능
- [x]  **5. 당첨 통계 기능 구현**
    - 저장된 당첨 번호와 사용자 로또 목록을 조회 요청
    - 조회된 데이터를 기반으로 도메인에 등수 계산 및 통계 집계 요청
    - 최종 통계 결과를 반환

### 3단계 : Adapter 계층

- [ ]  **6. CLI 입력 어댑터 구현**
    - 구매 금액 입력
        - [예외] 입력값이 숫자가 아닌 경우(`NumberFormatException`) 예외 처리
    - 당첨 번호(쉼표 구분) 및 보너스 번호 입력
        - [예외] 입력 형식이(e.g., 쉼표 구분) 잘못된 경우 예외 처리
- [ ]  **7. CLI 출력 어댑터 구현**
    - 구매한 로또 수량과 번호 목록을 형식에 맞게 출력
    - 당첨 통계(등수별 개수)를 형식에 맞게 출력
    - 총 수익률을 형식에 맞게 출력
        - [예외] 발생한 모든 예외를 `catch`하여 에러 메시지를 출력
